# کلید — نقشهٔ فنی ساخت

این سند همهٔ انتخاب‌های فنی پروژه را یک‌جا نگه می‌دارد. هر تصمیمی که عوض شود، اول همین‌جا عوض می‌شود.

## اصول راهنما

1. **یک زبان برای همه‌جا:** TypeScript، از برنامهٔ ویندوز تا سرور.
2. **یک کد رابط کاربری برای سه خروجی:** ویندوز (Electron)، وب، و گوشی (PWA).
3. **اول محلی (Local-first):** برنامه همیشه از دیتابیس روی همان دستگاه می‌خواند و در آن می‌نویسد. اینترنت فقط برای همگام‌سازی لازم است.
4. **مستقل از تحریم و قطعی اینترنت:** هر سرویسی که از ایران مسدود است یا در قطعی اینترنت بین‌الملل از کار می‌افتد، کنار گذاشته شده است.
5. **هر وابستگی خارجی پشت یک «رابط» (adapter):** درگاه پرداخت، سرویس پیامک و نقشه را می‌شود بدون دست زدن به بقیهٔ کد عوض کرد.

## نقشهٔ کلی

```
┌───────────── apps ─────────────┐     ┌──────────── سرور (ایران) ────────────┐
│ desktop  (Electron، ویندوز)    │     │ api      Fastify + TypeScript         │
│ web      (React، وب و PWA)     │◄───►│ PostgreSQL (جدا برای هر دفتر با RLS)  │
│ admin    (پنل فروشنده)         │ sync│ فضای فایل S3 (عکس‌ها، مدارک)          │
└────────────┬───────────────────┘     │ پیامک · درگاه پرداخت · مجوز اشتراک    │
             │                         └───────────────────────────────────────┘
┌──────── packages ────────┐
│ ui    سیستم طراحی و اجزا │
│ core  مدل داده، جستجو، همگام‌سازی، قوانین کسب‌وکار │
│ core/sql  طرح دیتابیس محلی (SQL دستی + migration) │
└──────────────────────────┘
```

| ابزار ساخت | Vite | سریع، و خروجی‌اش هم برای وب و هم برای Electron قابل استفاده است |

| کیفیت کد | ESLint، Prettier | |

| بخش | انتخاب | چرا |
|---|---|---|
| کتابخانه | React 19 | بزرگ‌ترین اکوسیستم و پایدار |
| مسیریابی | React Router | |
| ظاهر | توکن‌های CSS خود «کلید» (همان سیستم طراحی بوم) + CSS Modules | حالت تیره و روشن با یک تغییر؛ بدون وابستگی سنگین |

| قلم | وزیرمتن، **روی خود برنامه** (نه Google Fonts) | Google Fonts از ایران کند یا مسدود است؛ برنامهٔ آفلاین باید قلمش را همراه داشته باشد |
| تاریخ | تقویم جلالی با `Intl` (calendar: persian) | بدون کتابخانهٔ اضافه |

### داده روی دستگاه (آفلاین)
| بخش | انتخاب | چرا |
|---|---|---|
| دیتابیس ویندوز | SQLite با `better-sqlite3-multiple-ciphers` | سریع، و کل فایل دیتابیس با SQLCipher (AES-256) رمزگذاری می‌شود |
| دیتابیس وب و گوشی | SQLite WASM روی OPFS | همان دیتابیس و همان کوئری‌ها در مرورگر؛ فیلدهای حساس با Web Crypto رمز می‌شوند |
| لایهٔ دسترسی | SQL دستی پشت رابط `KelidStore` و `SqlDriver` (پیاده‌شده در `packages/core/src/sql`) | یک کد برای ویندوز، وب و تست؛ بدون وابستگی سنگین. Drizzle برای سرور در فاز ۲ بررسی می‌شود |
| جستجو | ستون `search` یکسان‌سازی‌شده (ی/ي، ک/ك، ارقام، نیم‌فاصله) با LIKE؛ FTS5 وقتی تعداد فایل‌ها زیاد شد | جستجوی فوری و کاملاً آفلاین |
| کلید رمزگذاری | ۳۲ بایت تصادفی برای هر دستگاه، قفل‌شده با DPAPI ویندوز (`safeStorage`) در `kelid.key`. قفل اضافه با رمز کاربر (Argon2id) با ورود کاربران در فاز ۳ | اگر فایل دیتابیس کپی شود، بدون حساب ویندوز همان کاربر خواندنی نیست |

### همگام‌سازی
طراحی اختصاصی و ساده، چون کنترل کامل لازم است: جدا بودن دفترها، اعمال اشتراک، و میزبانی در ایران.

- هر رکورد یک شناسهٔ یکتا (UUIDv7) دارد که روی خود دستگاه ساخته می‌شود؛ پس ثبت آفلاین با دستگاه دیگر تداخل نمی‌کند.
- هر تغییر محلی در یک «صف ارسال» (outbox) نوشته می‌شود و با وصل شدن اینترنت فرستاده می‌شود.
- دریافت تغییرها با «نشانگر» انجام می‌شود: «هرچه بعد از نسخهٔ N عوض شده را بده».
- تعارض‌ها **برای هر فیلد جداگانه** حل می‌شوند: آخرین تغییر برنده است (با ساعت ترکیبی HLC). اگر هر دو طرف یک فیلد مهم را عوض کرده باشند (قیمت، شمارهٔ مالک)، کاربر خودش انتخاب می‌کند؛ همان صفحه‌ای که در طرح هست.
- حذف واقعی انجام نمی‌شود و رکورد فقط علامت «حذف‌شده» می‌گیرد.
- **شمارهٔ پلاک فایل** (۰۲۷، ۰۵۳…) را سرور می‌دهد. فایلی که آفلاین ثبت شده، تا اولین اتصال پلاک موقت دارد.

### سرور
| بخش | انتخاب | چرا |
|---|---|---|
| زبان و چارچوب | Node.js 22 + Fastify | سریع، سبک، TypeScript |
| دیتابیس | PostgreSQL 16 با Row-Level Security | اطلاعات هر دفتر در سطح دیتابیس از بقیه جداست |
| فایل‌ها | فضای ذخیره‌سازی سازگار با S3 (ابر ایرانی یا MinIO) | عکس‌ها و مدارک |
| ورود | شمارهٔ همراه + کد پیامکی، توکن JWT کوتاه‌مدت + توکن تمدید برای هر دستگاه | |
| مجوز اشتراک | توکن امضاشده (Ed25519) با تاریخ انقضا و مهلت آفلاین | برنامه بدون اینترنت هم می‌تواند اعتبار اشتراک را بسنجد |
| کارهای زمان‌بندی‌شده | pg-boss (صف روی همان PostgreSQL) | پیامک یادآوری، پایان اشتراک، پشتیبان‌گیری |
| بسته‌بندی | Docker | راه‌اندازی یکسان روی هر سرور |

### سرویس‌های بیرونی (همه پشت adapter)
| بخش | پیشنهاد اول | جایگزین |
|---|---|---|
| میزبانی سرور | ابر ایرانی (لیارا، آروان‌کلاد یا پارس‌پک) | سرور مجازی ایرانی |
| درگاه پرداخت | زرین‌پال | آی‌دی‌پی، درگاه مستقیم بانک |
| پیامک | کاوه‌نگار | SMS.ir، ملی‌پیامک |
| نقشه | MapLibre GL با کاشی‌های نشان یا Map.ir | OpenStreetMap |

**چرا میزبانی ایرانی:** در قطعی اینترنت بین‌الملل، سرور داخلی همچنان در دسترس دفترهاست. بیشتر سرویس‌های ابری خارجی هم کاربر ایرانی را مسدود می‌کنند.

### برنامهٔ ویندوز
| بخش | انتخاب |
|---|---|
| پوسته | Electron (رابط کاربری داخل خود برنامه بسته‌بندی می‌شود) |
| فایل نصب | electron-builder با نصب‌کنندهٔ NSIS (`.exe`) |
| به‌روزرسانی خودکار | electron-updater از سرور خودمان |
| امکانات ویژه | نمایش به مشتری روی مانیتور دوم، چاپ مستقیم برگهٔ فایل، اجرا با روشن شدن ویندوز |

### وب و گوشی
| بخش | انتخاب |
|---|---|
| PWA | vite-plugin-pwa (Workbox): نصب روی صفحهٔ اصلی و کار آفلاین |

### پنل فروشنده
یک برنامهٔ React جدا (`apps/admin`) با همان سیستم طراحی، روی همان سرور و با دسترسی جداگانه.

## مسیر ساخت

| فاز | خروجی | نتیجه |
|---|---|---|
| ۰ | مخزن، سیستم طراحی در کد، قاب برنامه | برنامه در مرورگر و ویندوز باز می‌شود |
| ۱ | فایل‌ها، مشتری‌ها، جستجو، ثبت فایل، نمایش به مشتری، **کاملاً آفلاین روی یک دستگاه** | قابل استفاده برای یک مشاور تنها |
| ۲ | سرور، ورود با پیامک، همگام‌سازی چنددستگاهی | دفتر با چند دستگاه |
| ۳ | دفترها، همکاران و دسترسی‌ها، اشتراک، پرداخت، پنل فروشنده | آمادهٔ فروش |
| ۴ | تقویم، قراردادها، نقشه، پیامک یادآوری، فایل نصب و به‌روزرسانی خودکار | محصول کامل |
| ۵ | آزمایش با چند دفتر واقعی و اصلاح بر اساس بازخورد | انتشار |

## تصمیم‌هایی که با صاحب کار است

- **نماد اعتماد الکترونیکی (اینماد):** درگاه‌های پرداخت بدون آن فعال نمی‌شوند. بهتر است زود اقدام شود.
- **امضای دیجیتال فایل نصب ویندوز:** بدون امضا، ویندوز هنگام نصب هشدار SmartScreen می‌دهد. خرید گواهی امضا از ایران به خاطر تحریم سخت است. در شروع، هشدار با راهنمای نصب مدیریت می‌شود.
- **انتخاب نهایی** سرویس ابری، درگاه پرداخت و سرویس پیامک.
- **قیمت پلن‌ها و طول دورهٔ آزمایشی.**
